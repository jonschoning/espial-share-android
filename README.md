# espial-share-android
Provides an Android Share intent for adding bookmarks to Espial https://github.com/jonschoning/espial

Basic implementation provided for:
  - Settings
  - Espial Share: Add
    - shows the Add Bookmark page with pre-populated info
  - Espial Share: Read Later
    - quickly adds the bookmark, and marks it unread, without any user input

### Installing

The APK is signed but not published to the Play Store. If you're updating from a previous install and the signature has changed, uninstall the old version first, then install the new APK. After updating, open Settings and re-save your Espial server settings to make sure they reload correctly.
